## 0. Что важно понять до начала

Сам лендинг собирается **в Tilda Publishing (Zero Block)** — это ручная работа в визуальном
редакторе, Codex её не делает. Codex делает **всё остальное**, то есть весь технический слой,
от которого зависит бюджет и сохранность лидов:

1. Серверный обработчик заявок (webhook-приёмник + очередь + доставка в MAX).
2. JS/CSS-модули, которые вставляются в Tilda (мультилендинг, квиз, sticky-bar, UTM, reCAPTCHA, Метрика).
3. nginx-конфиг склейки доменов с сохранением query-строки.
4. Парсер витрины с investauto71.ru → JSON + оптимизированные WebP-фото для наполнения Tilda.
5. Кастомная 404.

**Главный риск проекта, из-за которого нельзя брать готовые коннекторы (Albato/Make):**
в компании действует SLA — первый контакт с лидом за 15 минут. Потеря UTM-меток при
редиректе или задержка доставки лида считаются браком работы.

## 3. Серверный обработчик заявок (ключевой узел)

### 3.1 Приём

- `POST /lead`, `Content-Type: application/x-www-form-urlencoded` или `application/json`
  (Tilda шлёт form-urlencoded).
- **Отвечать `200 OK` немедленно**, до любой внешней сети. Tilda считает заявку
  доставленной по коду ответа; вся доставка в MAX — асинхронно.
- Целевое время ответа: < 200 мс. Тело ответа: `{"ok":true,"id":"<lead_id>"}`.
- Идемпотентность: ключ = sha1(телефон + timestamp-минута + шаг квиза); повтор в пределах
  60 секунд не создаёт второй лид.

### 3.2 Единый JSON-пакет

Собирать один объект, включающий **все** данные:

```json
{
  "lead_id": "2026-09-17T12-04-31-a1b2c3",
  "received_at": "2026-09-17T12:04:31.552Z",
  "contact": {
    "phone": "+79539708877",
    "name": null,
    "preferred_channel": "MAX | Telegram | WhatsApp | Звонок"
  },
  "quiz": {
    "purpose": "Работа в такси | Личные поездки | Хочу выкупить авто",
    "class": "Эконом из наличия от 1800 ₽/сутки | Комфорт из наличия | Под заказ с авансом 20%",
    "fuel_gearbox": "Только Газ (ГБО) | Бензин | МКПП | АКПП",
    "qualifies": true,
    "reject_reason": null
  },
  "utm": {
    "utm_source": "...", "utm_medium": "...", "utm_campaign": "...",
    "utm_term": "...", "utm_content": "...",
    "yclid": "...", "referrer": "...", "landing_url": "..."
  },
  "recaptcha": { "score": 0.9, "action": "quiz_submit", "passed": true },
  "routing": { "target": "max_corporate", "priority": "hot | cold" },
  "meta": { "ua": "...", "ip_hash": "...", "device": "mobile" }
}
```

### 3.3 Квалификация трафика (отсев на сервере, не только в UI)

Жёсткие фильтры ТЗ: **только граждане РФ, возраст от 23 лет, стаж от 3 лет.**
Шаг 4 квиза — «Подходите ли вы под наши требования?» с вариантами
«Да, РФ, от 23 лет, стаж от 3-х лет» / «Нет, по какому-то пункту не прохожу».

- Ответ «Нет» → лид помечается `qualifies:false`, `priority:"cold"`, **в MAX уходит
  отдельным потоком/тегом**, а не в общий горячий поток. Совсем не терять его нельзя:
  это не мусор, это отказ по критерию.
- Пустой или подозрительный телефон, score reCAPTCHA < 0.3 → `spam`, в MAX не отправлять,
  писать в лог + отдельную таблицу.

### 3.4 Очередь и доставка в MAX

- Персистентная очередь в SQLite (`leads`, `outbox`): лид сохраняется на диск **до**
  первой попытки отправки. Перезапуск процесса и падение VPS не теряют заявку.
- Воркер шлёт в корпоративный мессенджер MAX по API-токену.
- Ретраи с экспоненциальной паузой: 1с → 3с → 10с → 30с → 2м → 5м → 15м, максимум 8 попыток.
- Если MAX недоступен дольше 10 минут — fallback-уведомление (Telegram-бот или e-mail
  ответственному), чтобы SLA 15 минут не сгорел молча. Канал fallback согласовать с заказчиком.
- Полный лог каждой попытки: время, http-код, тело ответа, номер попытки.
- `GET /health` отдаёт: размер очереди, время последней успешной отправки, число лидов за сутки.

### 3.5 Безопасность и 152-ФЗ

- Проверка reCAPTCHA v3 **на сервере** (secret key в `.env`, не в Tilda).
- Rate limit по IP: 10 заявок / 10 минут.
- Чекбокс согласия на обработку ПДн — обязательное поле, флаг согласия и версия
  политики пишутся в лид.
- IP хранить только в виде хэша; логи с ПДн ротировать (30 дней).
- Все секреты — в `.env`, в репозиторий не коммитить.

## 4. Модули для Tilda

### 4.1 `utm.js` — сохранность меток

Забирать метки из `location.search` при первом заходе, класть в `sessionStorage`,
подставлять в скрытые поля всех форм. Метки должны переживать переходы по якорям
и открытие квиза. Именно этот модуль страхует потерю UTM при редиректах.

### 4.2 `multilanding.js` — динамическая подмена H1

Словарь по вхождению подстроки в `utm_campaign` / `utm_term` / `utm_content`:

| Условие | H1 |
|---|---|
| базовый (меток нет) | «Автомобили под такси и личные цели с правом выкупа от 1800 ₽/сутки» |
| метка содержит `arenda` | «Аренда автомобилей под такси и личные цели от 10 дней и 1800 ₽/сутки» |
| метка содержит `vikup` | «Автомобили под выкуп от 1800 ₽/сутки. Одобрение с любой КИ» |

Подзаголовок постоянный: «Одобрение за 30 минут по 2 документам. Только для граждан РФ».
Подмена — до первой отрисовки (без мигания дефолтного текста): скрипт в `<head>`,
текст выставляется до показа hero.

### 4.3 `quiz.js` + `quiz.css` — генератор заявок

Заголовок: «Ответьте на 4 вопроса, чтобы узнать, какие автомобили свободны сегодня,
и получите расчет платежа». Обязателен визуальный прогресс-бар (геймификация).

- Шаг 1: Для каких целей нужен автомобиль? (Работа в такси / Личные поездки / Хочу выкупить авто)
- Шаг 2: Какой класс авто рассматриваете? (Эконом из наличия от 1800 ₽/сутки / Комфорт из наличия / Купить авто под заказ с авансом 20%)
- Шаг 3: Предпочтения по топливу и КПП? (Только Газ (ГБО) / Бензин, МКПП / АКПП)
- Шаг 4: Подходите ли вы под наши требования? (Да, РФ, от 23 лет, стаж от 3-х лет / Нет, по какому-то пункту не прохожу)
- Шаг 5 (контакты): выбор канала связи — **MAX / Telegram / WhatsApp / Жду звонка**;
  поле телефона с жёсткой маской `+7 (___) ___-__-__`; кнопка «Получить предложение».

Кнопка «Далее» disabled до выбора ответа; на шаге контактов — до валидного телефона.
Ошибка поля — красная граница `#D9534F` + потряхивание + подсказка.
Отправка — одним POST на `/lead` (весь пакет сразу), затем экран «спасибо».

### 4.4 `sticky-bar.js` — прилипающая панель

Только мобильная версия (скрывать от 720px). Две кнопки: **Звонок** и **Чат**.
Обязателен учёт `env(safe-area-inset-bottom)`; `body` получает нижний padding,
чтобы панель не перекрывала контент и кнопку отправки квиза.

### 4.5 `metrika-goals.js`

Цели Яндекс.Метрики: отправка формы, старт квиза, каждый шаг квиза, клик по мессенджерам,
клик по номеру телефона. Настроить сбор аудиторий для ретаргетинга.

### 4.6 `404.html`

Кастомная страница с кнопкой «Вернуться в каталог авто».

## 5. Склейка доменов (nginx)

- Wildcard 301 со всех зеркал (`avtocar71.ru`, `xn--71-6kcaj2c1aso.xn--p1ai`, их `www`)
  на `https://autocar71.ru`.
- **Переклейка всех старых внутренних URL на главную нового сайта**, но с безусловным
  сохранением query-строки:

```nginx
server {
  server_name avtocar71.ru www.avtocar71.ru xn--71-6kcaj2c1aso.xn--p1ai www.xn--71-6kcaj2c1aso.xn--p1ai;
  return 301 https://autocar71.ru/$is_args$args;
}
```

Ключевой момент: конструкция `$is_args$args` (или `$request_uri`, если путь нужно
сохранять) — без неё UTM-метки теряются и CPL перестаёт считаться.
**Встроенный редиректор Tilda для этой задачи не подходит** — он рубит параметры.

- SSL-сертификаты (Let's Encrypt) выпустить и автопродлевать на **всех** зеркалах,
  иначе браузер покажет предупреждение до редиректа.
- Проверить цепочку: `http://avtocar71.ru/old/page?utm_source=yandex&utm_term=arenda`
  → один 301 → `https://autocar71.ru/?utm_source=yandex&utm_term=arenda`.

## 6. Парсер витрины investauto71.ru

Актуальный прайс-лист и реальные фото автомобилей берутся с **investauto71.ru**.

`scripts/parse-investauto.js`:
- обходит каталог, собирает по каждой машине: марка, модель, год выпуска, тип топлива,
  тип КПП, класс, цена (единая крупная цена вида «от 1800 ₽/сутки (Аренда / Выкуп)»),
  ссылка на карточку, ссылки на фото;
- пишет `data/cars.json`;
- `scripts/images.js` скачивает фото, ресайзит под карточку витрины, конвертирует в WebP
  (и оставляет jpg-фоллбек), раскладывает в `data/img/<slug>/`.

Выход используется для ручного наполнения витрины в Tilda (карточки-слайдеры Zero Block
с разбивкой по классам авто) и для повторной сверки цен при обновлении прайса.

Pop-up по клику на карточку: условия — фиксированный депозит **25 000 ₽** для авто из
наличия, **100 000 ₽** для новых авто; кнопка «Проверить доступность» открывает квиз.

## 9. Критерии приёмки

1. `POST /lead` отвечает `200 OK` быстрее 200 мс при недоступном MAX; лид не теряется,
   уходит после восстановления связи (проверяется остановкой воркера на 5 минут).
2. Перезапуск сервера с непустой очередью не теряет ни одного лида.
3. Переход `http://avtocar71.ru/любой/путь?utm_source=test&utm_term=vikup` даёт ровно один
   301 на `https://autocar71.ru/` с **полностью сохранённой** query-строкой.
4. H1 меняется по меткам `arenda` / `vikup` без мигания дефолтного варианта.
5. Квиз: нельзя перейти дальше без ответа; телефон валидируется маской; ошибка
   подсвечивается `#D9534F`; итоговый пакет содержит все 4 ответа + канал + телефон
   + полный набор UTM + score reCAPTCHA.
6. Ответ «Нет, не прохожу» на шаге 4 помечает лид `qualifies:false` и не смешивает его
   с горячим потоком.
7. Google PageSpeed Insights (mobile) ≥ 90 на опубликованной странице.
8. Sticky-bar не перекрывает контент на iPhone с «чёлкой» (safe-area), скрыт на планшете+.
9. Ни один кегль на странице не меньше 16px.
10. В Метрике фиксируются цели: отправка формы, старт квиза, клик по мессенджеру,
    клик по телефону.
11. Все секреты только в `.env`; в репозитории нет токенов.

## 10. Порядок работ для Codex

1. `server/` — каркас, `POST /lead`, нормализация, SQLite-очередь, тесты на потерю связи.

5. `tilda/sticky-bar.js`, `recaptcha-init.js`, `metrika-goals.js`, `404.html`.
6. `nginx/` — конфиги зеркал, инструкция по SSL.
7. `scripts/parse-investauto.js` + `images.js` — наполнение витрины.
8. `README.md` — развёртывание на VPS «с нуля»: node, systemd unit, nginx, certbot,
   переменные окружения, smoke-тест отправки лида.
