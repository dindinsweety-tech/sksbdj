# Прототип корпоративного сайта завода полипропилена

Кликабельный MVP-прототип, собранный по ТЗ на разработку корпоративного сайта
завода (проект на fl.ru, CMS 1С-Битрикс).

- `prototype/poliom-mvp.html` — исходник прототипа (один файл, без сборки).
- Опубликованная версия: https://claude.ai/code/artifact/16f1dc72-2780-46c4-aea9-b19bbbf69afb

## Что показывает прототип

21 экран и сквозная навигация: главная с маршрутами для пяти аудиторий,
«О предприятии» (обзор, история-таймлайн, ИСМ и документы с фильтрацией),
«Производство и технологии» с интерактивной технологической цепочкой,
каталог марок с фильтрами, поиском и карточкой марки (TDS, паспорт качества,
переход в коммерческий сервис), интерактивный блок «Полипропилен вокруг нас»,
раздел-навигатор «Устойчивое развитие» (экология, ОТ и ПБ, социальные проекты,
комплаенс), карьера с вакансиями и откликом через hh.ru, пресс-центр с
фильтрами и универсальным шаблоном материала, контакты и B2B-сервисы.

Сервисы: универсальная форма обратной связи с маршрутизацией по теме,
анонимная комплаенс-форма, чат-бот со сценариями, поиск по сайту,
переключатель RU/EN, светлая и тёмная темы, адаптив от смартфона до десктопа.

## Важно

Демонстрационный макет. Не является официальным сайтом какой-либо компании.
Все цифры, тексты, новости и вакансии — условные, для показа логики интерфейса.
