# Демо-прототипы и рабочие проекты

Репозиторий с кликабельными прототипами под заказы и с техническим слоем
проектов, которые ушли в работу. Статика публикуется через GitHub Pages
из каталога `docs/`.

## Проект в работе

### Автокар71 — аренда и выкуп автомобилей (autocar71.ru)

- **Демо для заказчика:** https://dindinsweety-tech.github.io/sksbdj/autocar71/
- Технический слой (Этап 1): [`autocar71/`](autocar71/) — приёмник заявок на Node.js,
  модули для Tilda, конфиги nginx, парсер витрины investauto71.ru.
- ТЗ и договор: [`briefs/autocar71-codex.md`](briefs/autocar71-codex.md),
  [`briefs/autocar71-dogovor.md`](briefs/autocar71-dogovor.md).

Демо-страница показывает готовую структуру лендинга: hero с мультилендингом,
витрину автопарка с фильтрами и pop-up условий, блок требований и графика 7/0,
квиз-генератор заявок со сборкой JSON-пакета, отзывы и реальные выдачи,
карту офиса, подвал с реквизитами, политику обработки ПДн и кастомную 404.

## Прототип корпоративного сайта завода полипропилена

Кликабельный MVP по ТЗ на корпоративный сайт завода (проект на fl.ru, CMS 1С-Битрикс).

- `prototype/poliom-mvp.html` — исходник прототипа (один файл, без сборки).
- Опубликованная версия: https://claude.ai/code/artifact/16f1dc72-2780-46c4-aea9-b19bbbf69afb

21 экран и сквозная навигация: главная с маршрутами для пяти аудиторий,
«О предприятии» (обзор, история-таймлайн, ИСМ и документы с фильтрацией),
«Производство и технологии» с интерактивной технологической цепочкой,
каталог марок с фильтрами, поиском и карточкой марки (TDS, паспорт качества,
переход в коммерческий сервис), интерактивный блок «Полипропилен вокруг нас»,
раздел-навигатор «Устойчивое развитие», карьера с вакансиями и откликом через hh.ru,
пресс-центр с фильтрами и универсальным шаблоном материала, контакты и B2B-сервисы.

## Остальные демо

В `prototype/` и `docs/` лежат прототипы под другие заказы: каталог авто из Китая,
CRM клининга и логистики, аналитика Ozon, HR-скоринг, конструктор фильтров матчей,
автоматизация amoCRM, парсер оборудования и другие.

## Важно

Демонстрационные макеты. Цифры, тексты и данные в прототипах — условные,
для показа логики интерфейса, если не указано иное.
