Журнал синхронизации

Повторный запуск не создаёт дублей: записи кладутся по ключу «магазин + тип + идентификатор операции».

Ограничения, которые надо знать заранее. Seller API отдаёт финансовые операции пачками с лимитом по частоте — первичная загрузка 90 дней идёт очередью с паузами, примерно 10–20 минут на магазин с тысячей товаров. Часть удержаний появляется в отчётах с задержкой до нескольких суток, поэтому цифры за последние дни уточняются задним числом. Это не баг сервиса, это поведение площадки, и в интерфейсе оно должно быть подписано.
