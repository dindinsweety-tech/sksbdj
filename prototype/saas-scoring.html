Архитектура

Где живёт алгоритм

Главное требование заказа: формулы и текстовая база не должны попадать в браузер. Ниже — как это устроено в боевой версии.

Что уходит в браузер

Только готовые строки отчёта и числа для отрисовки шкал. Ни формул, ни правил сопоставления, ни полной базы текстов — клиент получает ровно тот кусок, который относится к конкретному кандидату.

Что остаётся на сервере

Алгоритм, база текстов, генерация PDF. Плюс лимиты по тарифу, чтобы через API нельзя было выкачать базу перебором дат — это реальный вектор кражи алгоритма, и его закрывают троттлингом и логированием.

Честно о защите PDF. Полностью запретить копирование текста из PDF нельзя — можно поставить пароль на редактирование, снять слой выделения, отдавать страницы растром и нанести видимый и невидимый водяной знак с ID пользователя. Последнее работает лучше запретов: утечку видно и понятно, чей это файл.
Про это демо. Страница статическая, поэтому расчёт здесь выполняется в браузере по упрощённой открытой формуле и служит только для показа интерфейса. В боевой версии этого кода в браузере нет вообще.
