Агент операционки · МойСклад

Сверка платежей и приёмка по команде — там, где агент реально экономит часы

Две операционные задачи из брифа, собранные как работающая логика. Первая — сопоставление банковской выписки с платежами в учётной системе: не «нашлось / не нашлось», а с допусками, оценкой уверенности и разбором спорных случаев. Вторая — приёмка по заказу поставщика, которую агент собирает из фразы человеческим языком и сам считает расхождения.

Главный принцип: агент не проводит документы молча. Он предлагает решение с обоснованием, а спорные случаи выносит человеку. Автопроведение включается только для совпадений с высокой уверенностью — порог настраивается ниже.
